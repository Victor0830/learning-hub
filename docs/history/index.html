世界史與台灣史

歷史，是一連串的「為什麼」

看台灣吧的影片覺得歷史好有趣，到了學校卻只剩一條條要背的重點？問題不是你不會念歷史，而是手上少了一副骨架。有了骨架，每個重點都有地方可以掛上去。

🎯 這個單元想幫你做到……

  • 腦中有一條台灣四百年的時間軸，知道每個重點屬於哪個時代
  • 看到一件事，會問「為什麼會發生？後來造成什麼？」
  • 發現台灣的每一次大轉變，背後幾乎都有世界上的大事在推動
  • 把影片裡的故事和課本的重點接在一起
為什麼會變片段三層骨架世界的浪國中歷史學什麼怎麼用這個單元
🗺️ 台灣 × 世界年表七個時代，台灣和世界並排看；每個時代有一張骨架卡。 🔗 因果鏈練習背景、導火線、經過、影響：把事件串成故事，還有排序和選擇題。 📝 看影片筆記卡看完影片或上完課寫一張卡，卡片會自動排進時代，變成自己的年表。

一為什麼影片好懂，課本卻變成片段？

國一的歷史課一週只有一節，老師要在很短的時間講完一整個時代，只好先交代「考試會考的結論」。影片則有時間把前因後果慢慢說完。

課堂重點（時間不夠時）好看的歷史影片
講什麼發生了什麼、哪一年為什麼會發生、當時的人怎麼想
像什麼一顆一顆的珠子把珠子串起來的線
記憶方式背起來，考完容易忘懂了故事，自然記得
缺點缺少前因後果為了好懂會簡化，有時只講一種角度
📌 兩個都需要

課本給你正確的珠子（人、事、時、地），影片給你串珠子的線（因果）。這個單元要做的，就是準備一個放珠子的架子：時代骨架。

二歷史的三層骨架

  1. 第一層：時代座標（在哪裡？）
    先知道台灣歷史分成哪幾個時代、各有多長。聽到任何事件，第一步是把它放進對的時代。
  2. 第二層：因果鏈（為什麼？）
    每個事件都有背景（長期累積的原因）、導火線（直接引爆的事）、經過，和影響。影響又常常變成下一件事的背景。
  3. 第三層：世界的連動（誰在推？）
    台灣是海上的島，世界的大浪一打過來，台灣就跟著改變。把「同時的世界」擺在旁邊看，很多「為什麼」就有答案了。

每個時代都可以用同一組問題來整理，這就是骨架卡：

① 誰來了？這時候誰在統治、誰搬進來？
② 為什麼來？他們想從台灣得到什麼？
③ 怎麼管理？用了哪些政策、做了哪些建設？
④ 人民怎麼回應？接受、合作、還是反抗？
⑤ 留下什麼？哪些東西一直影響到今天？

三一張表看懂：世界的浪，打到台灣

台灣近四百年來換了好幾次統治者。仔細看會發現，每一次轉變的起點，幾乎都在台灣外面。

世界（含中國、東亞）發生了什麼台灣因此……
大航海時代，歐洲人到亞洲做生意；明朝不讓外國人隨便來貿易1624 年荷蘭在大員建立據點，台灣成為貿易轉運站
1644 年明朝滅亡，清朝統治中國；鄭成功抗清失利1662 年鄭成功趕走荷蘭人，把台灣當成反清基地
清朝要消滅最後的反抗勢力1683 年鄭氏投降，台灣被納入清朝版圖
工業革命後，英法用戰爭逼清朝開放通商1860 年代開港，茶、糖、樟腦賣到全世界
日本明治維新變強，1894 年甲午戰爭打敗清朝1895 年《馬關條約》，台灣成為日本殖民地
二戰結束、國共內戰、冷戰和韓戰中華民國政府來台，長期戒嚴；在美援下發展經濟
1980 年代末全球民主浪潮，冷戰結束1987 年解嚴，走向民主化
💡 但台灣不是只會「被推著走」

外面的浪決定了什麼時候改變，但台灣的人怎麼回應，決定了改變變成什麼樣子。例如日治時期的人從武裝抗日轉向文化和議會請願，戰後的人一邊打拼經濟、一邊爭取民主。看歷史時，兩邊都要看。

四國中三年的歷史在學什麼？

現在的課綱（108 課綱），國中歷史大致是由近到遠、由自己到世界：

國一：台灣史→ 國二：中國與東亞史→ 國三：世界史

國一先學台灣史：上學期多半從史前講到清朝，下學期講日治和戰後（各版本教科書的切法可能略有不同，以學校課本為準）。

🧭 為什麼現在就要看世界？

國一雖然還沒上世界史，但台灣史的很多「為什麼」答案在世界史裡。現在先在年表上認識幾個世界大事的名字（大航海、工業革命、明治維新、兩次世界大戰、冷戰），到國二、國三再學就會有「啊，原來是這個！」的感覺。

五怎麼用這個單元？

建議配合學校進度，一週一個小循環，每次 20–30 分鐘就夠：

  1. 上完歷史課：打開 年表，找到老師今天講的事件在哪個時代，看看旁邊的世界同時發生什麼。
  2. 找一支相關的影片看：例如台灣吧講到同一個時代的影片。看的時候專心抓「為什麼」。
  3. 寫一張 筆記卡：用背景、導火線、經過、影響整理，卡片會自動排進時代裡。
  4. 說給家人聽（5 分鐘）：不看筆記，用「因為……所以……後來……」把故事講一遍。講得出來，才是真的懂。
  5. 考前：做 因果鏈練習，再把自己的卡片從頭看一遍，就是一份自己做的複習年表。
⚠️ 看影片的小提醒

影片為了好看，常會簡化、用比喻，偶爾也會只講一種立場。看完可以對照課本：年份、人名有沒有一樣？如果影片和課本說法不同，就是一個很好的問題，可以帶去問老師。
