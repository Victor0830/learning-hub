第二層骨架：因果鏈

事件為什麼會發生？

好看的歷史影片，厲害的地方就是把「為什麼」講清楚。這一頁把影片的講故事方法拆成四個格子，讓你自己也能把課本的重點串成故事。

🎯 這一頁學完，你會……

  • 分得出一件事的背景、導火線、經過、影響
  • 知道原因有很多種：政治、經濟、地理、戰爭、思想、人物
  • 用「因為……所以……後來……」把一段歷史說清楚
四個格子原因的種類五條因果鏈練習題

工具 1因果鏈的四個格子

先用一場火災來想：

背景房間裡堆滿紙箱和乾木頭，很久都沒整理。
長期累積、早就存在的原因
導火線有人丟了一根沒熄的菸蒂。
直接引爆事件的那一下
經過火燒起來，消防車趕來滅火。
事情怎麼發展
影響房子要重建，大家開始裝煙霧偵測器。
留下的改變
📌 最常搞混的地方

背景是「早就堆好的柴」，導火線是「點火的那一下」。只有菸蒂、沒有乾柴，不一定會燒起來；只有乾柴、沒人點火，也可能一直沒事。考題很愛問「下列何者是某事件的導火線」，選項裡常常混著背景。

💡 還有兩個小祕密
  • 影響常常變成下一件事的背景。歷史就是這樣一環扣一環連下去的。
  • 不是每件事都有一個明確的導火線。有些改變是很多力量慢慢推出來的，這時候就寫「推力」。

工具 2原因有很多種

問「為什麼」時，可以拿這張清單檢查自己有沒有漏掉哪一種：

🏛️ 政治誰掌權、政府的政策、國與國的關係
💰 經濟賺錢、貿易、土地、稅
🗺️ 地理位置、航線、氣候、物產
⚔️ 戰爭打仗的輸贏、簽了什麼條約
💡 思想新的想法傳進來，例如民主、民族自決
🙋 人物關鍵人物的選擇和個性

工具 3五條因果鏈：看故事怎麼串起來

先自己讀一遍，再試著不看畫面，把整條鏈說給家人聽。

① 荷蘭人為什麼跑來台灣？

  1. 背景大航海時代，歐洲國家搶著到亞洲買絲綢、瓷器、香料。1602 年荷蘭成立東印度公司，專做亞洲生意。
  2. 背景明朝實施海禁，不讓外國人隨便靠岸貿易。荷蘭想找一個靠近中國的據點。
  3. 導火線1622 年荷蘭佔領澎湖，1624 年被明朝軍隊逼退。
  4. 經過荷蘭轉往大員（今台南安平）。台灣剛好在中國、日本、東南亞的航線中間，當時也沒有一個統一全島的政權。
  5. 影響台灣成為貿易轉運站；荷蘭招募漢人來開墾，漢人移民開始大量來台。
💰 經濟🏛️ 政治🗺️ 地理

如果明朝當年願意讓荷蘭在澎湖通商，台灣的歷史可能會有什麼不同？

② 台灣為什麼會「開港」，把茶和樟腦賣到全世界？

  1. 背景英國發生工業革命，工廠生產大量商品，需要更大的市場和原料。
  2. 背景清朝只開放少數港口，貿易限制很多；英國向中國買很多茶葉，後來用賣鴉片來賺回白銀。
  3. 導火線鴉片戰爭（1840–1842）、英法聯軍（1856–1860），清朝都打輸了。
  4. 經過清朝被迫簽下《天津條約》等條約，開放更多港口。台灣的淡水、雞籠、安平、打狗在 1860 年代陸續開港。
  5. 影響茶、糖、樟腦大量出口，洋行和外國傳教士來到台灣；北部因為茶和樟腦變得繁榮，台北的地位越來越重要。
💰 經濟⚔️ 戰爭🏛️ 政治

開港對台灣的人來說是好事還是壞事？可能對誰比較好、對誰比較不好？（想想種茶的農民、原本的大港口城市、山區的原住民。）

③ 台灣為什麼會變成日本的殖民地？

  1. 背景1868 年日本明治維新，學習西方的制度和技術，工業和軍隊快速變強。
  2. 背景日本想像歐美列強一樣向外擴張；清朝和日本都想影響朝鮮。
  3. 導火線1894 年朝鮮發生動亂，清朝和日本都出兵，爆發甲午戰爭。
  4. 經過清朝陸軍、海軍都大敗，1895 年簽下《馬關條約》。
  5. 影響台灣和澎湖割讓給日本。台灣人成立台灣民主國抗日，但失敗，台灣開始 50 年的日本統治。
⚔️ 戰爭🏛️ 政治💡 思想（學習西方）

甲午戰爭是因為朝鮮打起來的，戰場也不在台灣，為什麼最後是台灣被割讓？（提示：戰敗國當時常被要求割地、賠款；日本也想要一塊往南方發展的地方。）

④ 1921 年為什麼會出現台灣文化協會？

  1. 背景日本在台灣辦新式教育，培養出一批讀過書、懂現代知識的台灣知識分子。
  2. 背景台灣人在政治、教育、工作上受到差別待遇，也不能選出代表自己的議會。
  3. 導火線第一次世界大戰後，「民族自決」和民主思想流行，朝鮮有三一運動、中國有五四運動；在東京的台灣留學生也深受影響。
  4. 經過蔣渭水、林獻堂等人成立台灣文化協會，到各地辦演講、設讀報社；同時向日本帝國議會請願，要求設立台灣議會，前後持續十多年。
  5. 影響反抗方式從拿武器轉為文化和政治運動，喚起台灣人的自覺；台灣議會雖然沒有設成，卻留下爭取民主權利的經驗。
💡 思想🏛️ 政治🙋 人物

為什麼這個時期的人不再拿武器反抗，而改用演講和請願？（想想前一個時期武裝抗日的結果，以及這批人受過什麼教育。）

⑤ 台灣為什麼在 1987 年解除戒嚴？

  1. 背景經濟發展後，受教育的人和中產階級變多，越來越多人希望參與政治、有言論自由。
  2. 背景黨外人士長期爭取民主；1979 年美麗島事件後，社會更關注民主和人權；1986 年民主進步黨成立。
  3. 推力1980 年代國際上掀起民主化浪潮（例如 1986 年菲律賓人民推翻獨裁政權），美國也關注台灣的人權問題。
  4. 經過1987 年蔣經國總統宣布解除戒嚴，1988 年解除報禁。
  5. 影響可以自由組黨、辦報紙；1991–1992 年國會全面改選，1996 年第一次總統直選，台灣走向民主。
🏛️ 政治💰 經濟💡 思想🙋 人物

👀 不同的看法：解嚴主要是政府主動改革，還是民間力量爭取來的？不同的人強調的重點不一樣，很多說法認為兩種力量都有。

這條鏈沒有明確的「導火線」，只有很多「推力」。你覺得哪一個推力最重要？為什麼？

✍️ 練習題

選擇題

A. 因果排序：把卡片排成發生的順序

點下面的卡片，依照「先發生 → 後發生」排上去。排錯了點一下可以拿回來。

🔴 鄭成功為什麼來台灣？

  1. 1644 年明朝滅亡，清朝開始統治中國
  2. 鄭成功在東南沿海帶兵抗清
  3. 1659 年鄭成功攻打南京失敗
  4. 需要新的根據地，把目標轉向台灣
  5. 1662 年荷蘭投降，鄭氏開始統治台灣

🟡 台灣為什麼會建省？

  1. 1860 年代台灣開港，外國勢力越來越注意台灣
  2. 1874 年牡丹社事件，日本出兵恆春半島
  3. 沈葆楨來台加強防務，推動開山撫番
  4. 1884 年清法戰爭，法軍攻打基隆、淡水
  5. 清朝更加重視台灣，1885 年台灣建省

🌸 為什麼會有皇民化運動？

  1. 1929 年全球經濟大恐慌
  2. 日本經濟受到打擊，軍方勢力抬頭、主張向外擴張
  3. 1937 年中日戰爭爆發
  4. 日本需要台灣人在戰爭中全力配合
  5. 推動皇民化運動：說日語、改日本姓名，後來徵召台灣人當兵

🟢 戰後台灣經濟怎麼起飛？

  1. 1950 年韓戰爆發，冷戰在東亞升溫
  2. 美國派第七艦隊巡防台灣海峽，並提供美援
  3. 政府利用美援改善電力、交通等基礎建設
  4. 1966 年設立加工出口區，吸引外資、發展出口工業
  5. 台灣經濟快速成長，被稱為「經濟奇蹟」

B. 選擇題

下列哪一個是「荷蘭人來到台灣」的導火線？

(A) 是長期的背景；(C)(D) 是荷蘭來台之後的事。直接讓荷蘭「轉往台灣」的那一下，是在澎湖被逼退。

1895 年台灣被割讓給日本，是因為清朝在哪一場戰爭中戰敗？

這四場戰爭很容易搞混，各自牽動台灣不同的事：鴉片戰爭、英法聯軍 → 開港；清法戰爭 → 建省；甲午戰爭 → 割讓台灣；中日戰爭（1937）→ 皇民化運動。

「開港通商」以後，台灣最主要的三種出口商品是？

茶和樟腦主要產在北部山區，所以開港後北部興起；糖主要產在南部。(B) 鹿皮是荷蘭時期的重要出口，香蕉則是日治時期才大量外銷。

下列哪一組「世界大事 → 台灣的變化」配對是正確的？

先用時代檢查：工業革命在 1700 年代後期、冷戰結束在 1991 年、一戰在 1914 年，時間都對不上。只有 1644 年明朝滅亡和鄭成功 1662 年來台是同一段時間、也真的有因果關係。

1920 年代，台灣人反抗日本統治的方式有什麼變化？

1915 年西來庵事件後，大規模武裝抗日漸漸結束。受過新式教育的知識分子，受到一戰後民族自決思潮的影響，改用台灣文化協會、台灣議會設置請願運動等非武力的方式爭取權利。

小華說：「清朝統治台灣的時間很短，所以課本才只有幾課。」這句話哪裡有問題？

清朝從 1683 年統治到 1895 年，約 212 年。21 年是鄭氏時期。課本篇幅少不代表時間短，所以更需要自己用年表把清朝前期和後期分清楚。

「一件事的影響，常常變成下一件事的背景。」下列哪一個例子最符合這句話？

(B)(C)(D) 都只是單一事件的敘述，沒有說出「造成了什麼、又接到哪件事」。(A) 同時說了影響（清朝開始重視台灣）和它變成下一件事的背景（建省）。

「英國工廠需要更大的市場和原料」屬於哪一種原因？

市場、原料、賺錢、貿易，都是經濟原因。如果是「台灣位在航線中間」就屬於地理；「明朝實施海禁」屬於政治。

看影片時，發現影片說的年份和課本不一樣，最好的做法是？

影片和課本各有用處，也都可能簡化。遇到不一樣的地方，正是練習查證的好機會。考試時請以課本和老師的說法為準。

C. 自己說說看

用「因為……所以……後來……」說一條因果鏈

不看上面的因果鏈 ②，用 3–4 句話把「台灣為什麼會開港」寫出來。

因為英國發生工業革命，需要更大的市場，清朝卻限制貿易，所以英國和法國發動鴉片戰爭、英法聯軍。清朝打輸了，被迫簽條約開放港口，後來台灣的淡水、雞籠、安平、打狗在 1860 年代陸續開港，茶、糖、樟腦大量出口，北部也因此繁榮起來。

有講到「工業革命／需要市場 → 戰爭打輸 → 簽條約開港 → 出口與北部興起」這幾個環節就很棒，不用一字不差。

如果……會怎樣？

如果 1950 年沒有爆發韓戰，台灣後來的發展可能會有什麼不同？寫下你的推測和理由。

這題沒有標準答案，重點是理由說不說得通。可以參考的思考方向：

  • 1950 年初，美國政府曾表示不打算軍事介入台灣海峽；韓戰爆發後才改變態度，派第七艦隊巡防。
  • 如果沒有韓戰，美國可能不會那麼快支持台灣，也不一定會有後來的美援，台灣的安全和經濟發展都可能不一樣。

歷史不能重來，「如果」題是用來練習看出哪一個原因最關鍵。
