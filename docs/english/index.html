幼稚園中班在美國住過一年，回台灣後也一直上外師課；閱讀一路進步，口說、聽力和寫作卻好像沒跟上，特別是口說的語感和發音。這種狀況很常見，而且有原因可以解釋。

你不是「口說退步」。閱讀一直有在用、有在進步，口說、聽力、寫作卻沒有練到一樣多的量，差距才會越拉越大。

一為什麼閱讀進步了，其他能力沒跟上？

  1. 閱讀和口說是不同的能力

    閱讀是「看懂」，可以自己控制速度、回頭再看。口說和寫作是「說出來、寫出來」，要在當下從腦中快速找到字、組好句子。看得懂很多，不代表說得出來。

  2. 很多單字是用眼睛學的，沒有用耳朵學過

    靠閱讀學到的單字，多半是看拼字猜發音，沒聽過真人怎麼唸。常見的結果是重音放錯，例如 ˈphotograph 和 phoˈtography；或是看得懂的字，聽到時卻反應不過來。

  3. 語感要靠「聽很多、說很多次」累積

    語感其實是大量常用說法練到不用想就說得出口，例如 I'm about to…、It turns out…。這要靠大量聽加上反覆開口，懂文法不夠。外師課一週幾小時，扣掉老師講話和同學輪流的時間，自己實際開口的時間其實很少。

  4. 在美國那一年的耳朵基礎，後來沒有接著用

    那個年紀聽力和發音底子打得很快，但回台灣後少了大量聽和說，只有讀一直在用，所以只有閱讀持續成長。

  5. 國一的年紀比較怕說錯

    這個年紀自我意識變強，怕發音不標準、怕犯錯，就少開口；越少開口，越生疏。

二發音常卡的地方（照影響程度排）

→ 到「發音與節奏」頁聽發音、玩辨音遊戲

影響「別人聽不聽得懂」最大的，通常是節奏和重音，個別的音反而其次。

優先順序問題說明與例子
1句子節奏中文每個字差不多一樣長；英文是重要的字唸重唸長，功能字唸輕唸快。每個字都唸得一樣重，聽起來就「很台」。
2連音和弱讀want to 唸成 wanna，did you 唸成 didja。這也是聽力跟不上的主因：單字都會，連起來卻聽不出來。
3單字重音重音放錯位置，例如 ˈphotograph / phoˈtography。
4個別的音字尾子音（-d、-t、-l）被吃掉或多加一個「ㄜ」；th；v/w；長短母音（ship / sheep）；bad / bed 分不清。

三先做一次「診斷錄音」（約 10 分鐘）

→ 用「每月錄音」頁直接錄音、做聽寫並保存紀錄

先找出卡在哪一層，比直接加課有效。用手機錄下三段：

錄什麼時間看什麼
朗讀一段讀得懂的文章1 分鐘發音、重音、節奏
讀完後用英文重述內容1～2 分鐘找字的速度、句子組織
自由聊一個熟悉的話題1～2 分鐘流暢度、停頓、常用說法
🎧 再加一個聽力測試：聽寫

放一段自然速度的英文，一次聽一句，把聽到的寫下來。寫錯的地方，就是聽力斷掉的地方，通常都是連音和弱讀。

四練習方法（利用閱讀的優勢）

1. 跟讀（Shadowing）：練語感和發音最有效 → 去練習

素材怎麼挑

  • 1～2 分鐘、自然語速
  • 難度比閱讀程度低一點
  • 挑有興趣的主題，例如科學、動物

練習份量

  • 一段素材練一週
  • 每天 10～15 分鐘
  • 重點是模仿節奏和語調，不是把每個字唸清楚
  1. 只聽：先不看文字，聽懂大意。
  2. 看文字聽：注意哪些字唸得重、哪些字連在一起。
  3. 看文字跟著唸：原音一出來，馬上跟著唸，像影子一樣。
  4. 不看文字跟著唸：只靠耳朵模仿。
  5. 錄下來和原音比較：聽聽看節奏、重音哪裡不一樣。

2. 聽「讀過的書」的有聲書

已經知道內容，聽的時候負擔小，剛好把「眼睛認得的字」接上「耳朵聽得懂的聲音」。

3. 讀完就說：重述練習 → 去練習

讀完一篇文章或一個章節，用英文說給家人聽，或錄給自己聽。

💡 進階：4-3-2 練習

同一個內容，先說 4 分鐘，再說 3 分鐘，最後說 2 分鐘。時間越來越短，會自然逼出更流暢的說法。

4. 寫作從仿寫開始 → 去練習

  • 從閱讀中挑喜歡的句型，照樣造句。
  • 寫三到五句的讀後摘要。
  • 先說一遍再寫，寫作會順很多。

5. 調整外師課的用法

  • 跟老師講好，盡量增加孩子自己開口的時間（一對一時目標是孩子說 70% 的時間；一對多的課可以請老師多安排兩兩對話或輪流發表）。
  • 每次只挑一個重點修正（例如這週只抓字尾子音），不要每個錯都糾正。
  • 請老師錄下孩子說話的片段，回家可以重聽。
👥 一對多的外師課：每個人實際開口的時間很少

一週四小時聽起來很多，但分給每個孩子的開口時間其實有限。可以這樣把課程效果放大：

  • 上課前：先準備 3 句想在課堂上說的話（和當週主題有關），上課時一定找機會說出來。
  • 下課後：用英文把今天上課的內容重述給家人聽，一兩分鐘就好。

6. 用 AI 語音對話降低怕說錯的壓力

對國一的孩子來說，對著 AI 說錯不會丟臉，很適合拿來增加開口量。

素材參考

BBC Learning English有長度適中的 Podcast 和影片，可以拿來跟讀和聽寫。
讀過的英文書的有聲書內容熟悉，最適合接上耳朵和眼睛。
科學、動物主題例如 National Geographic Kids 的文章與影片，或 Brains On!、Wow in the World 這類兒少科學 Podcast。
