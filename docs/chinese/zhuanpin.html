成語、古文的詞性與轉品

「一樹火紅」的「火」和「紅」是什麼詞性？成語和古文裡的字常常「換工作」，這個單元教你一套固定的步驟，把詞性判斷從憑感覺變成有根據。

🎯 這個單元學完，你會……

  • 用「翻白話、看位置、找對稱」三步驟判斷成語和古文的詞性
  • 認得國中最常考的四種轉品
  • 用「判斷卡」一步一步寫出判斷理由
讀很多書也不會？解「一樹火紅」三步驟 四種轉品判斷卡文言文小幫手怎麼練練習題

零讀了很多課外書，詞性題還是不會？很正常！

📚 大量閱讀培養的是「讀得懂」的語感：你知道「一樹火紅」在寫一整棵樹開滿紅花。
🔍 詞性判斷需要的是「說得出」這個字在句子裡擔任什麼角色，這是另一種分析能力。

就像很會說中文的人，不一定說得出一句話的文法結構。你不是讀得不夠，而是還缺一套分析的步驟。這個單元就是要補上這一塊。

一先解「一樹火紅」

這題要分兩層來看。考題通常只問其中一層，所以第一步要先看清楚題目框起來的是哪個字。

第一層：拆開看「火」和「紅」

先把詞翻成白話：火紅 → 像火一樣地紅

字本來的詞性在這裡的作用詞性
火名詞修飾「紅」，說明怎麼紅（像火一樣）名詞當副詞用
紅形容詞描述顏色形容詞

判斷理由：「火」後面接的是形容詞「紅」。單元一學過，修飾形容詞的是副詞，所以名詞「火」在這裡當副詞用。

第二層：「火紅」整個詞在句子裡的角色

「一樹」是數量詞（「樹」在這裡借來當量詞，意思接近「滿樹」）。數量詞後面通常接名詞，像一本書、一片天空。

所以「一樹火紅」的「火紅」，指的是「火紅的花、火紅的景象」，屬於形容詞當名詞用。

📌 小結
  • 題目問「火」→ 名詞當副詞用
  • 題目問「紅」→ 形容詞
  • 題目問「火紅」整個詞在這句 → 形容詞當名詞用

不同參考書的標示方式可能略有差異，考試時以課本和老師的講法為準。

二三步驟判斷法（成語、古文都適用）

  1. 翻成白話

    把詞擴寫成完整的白話，看它在白話裡變成什麼。

    原文白話還原判斷
    狼吞虎嚥像狼一樣吞狼：名詞當副詞
    雪白像雪一樣白雪：名詞當副詞
    日新月異每天都有新的變化日：名詞當副詞（表時間）
    春風又綠江南岸使江南岸變綠綠：形容詞當動詞

    💡 翻出來如果多了「像……一樣」、「每……」、「使……變成」、「用……做」，幾乎可以確定這個字換了詞性。

  2. 看位置（前後接什麼）

    中文的詞性很看位置，這是最可靠的線索：

    位置通常是例子
    在數量詞、「的」、「之」、「其」後面名詞一樹火紅、一片蒼翠
    後面接受詞（被動作影響的對象）動詞又綠江南岸
    在「不」「將」「已」後面動詞或形容詞不言、將行
    在動詞或形容詞前面修飾副詞火紅、蜂擁
    在名詞前面修飾形容詞美景

  3. 利用成語的對稱結構

    四字成語常常兩兩對稱。對稱位置上的字，詞性通常相同，認出一個，就能推出另一個。

    東奔西走奔、走 → 動詞
    東、西 → 名詞當副詞（往東、往西）
    山明水秀山、水 → 名詞
    明、秀 → 形容詞
    狼吞虎嚥吞、嚥 → 動詞
    狼、虎 → 名詞當副詞（像狼、像虎）

三國中最常考的四種轉品

轉品（詞類活用）的例子多到背不完，但類型只有少數幾種。筆記請按類型整理，不要按課次整理。

① 名詞當副詞 （最常考）

翻譯關鍵：「像……一樣」、「每……」、「往……」、「按……」

  • 火紅、雪白、冰冷
  • 蜂擁而至、抱頭鼠竄、蠶食
  • 日新月異、東奔西走
  • 古文：〈狼〉「其一犬坐於前」→ 像狗一樣坐著
  • 古文：《論語》「學而時習之」→ 按時溫習

② 名詞當動詞

翻譯關鍵：「用……做某件事」、「做出……的動作」

  • 古文：〈狼〉「一狼洞其中」→ 在裡面打洞
  • 古文：〈黔之驢〉「驢不勝怒，蹄之」→ 用蹄踢牠
  • 成語：衣（ㄧˋ）錦還鄉 → 穿著華麗的衣服回到家鄉

判斷線索：名詞後面直接接受詞（之、其），通常就是當動詞用。

③ 形容詞當動詞

翻譯關鍵：「使……變得……」、「變得……」

  • 春風又綠江南岸 → 使江南岸變綠
  • 紅了櫻桃，綠了芭蕉 → 櫻桃變紅、芭蕉變綠

判斷線索：形容詞後面接了「了」或受詞。

④ 形容詞當名詞

翻譯關鍵：「……的東西」、「……的人」、「……的景象」

  • 一樹火紅、一片蒼翠、滿眼翠綠
  • 挑肥揀瘦 → 挑肥的、揀瘦的（東西）
  • 嫌貧愛富 → 嫌棄貧窮的人、喜愛富有的人

判斷線索：出現在數量詞或動詞後面。

四判斷卡：每一題都照著走

🃏 詞性判斷卡
  1. 這個字「本來」是什麼詞性？
  2. 翻成白話變成什麼？（有沒有多出「像、每、使、用」？）
  3. 它前面、後面接什麼？
  4. 所以在這裡是什麼詞性？屬於哪一種轉品？

示範：「一狼洞其中」的「洞」

  1. 「洞」本來是名詞。
  2. 翻成白話：一隻狼在柴堆裡打洞。多出了「打」這個動作。
  3. 後面接「其中」，是動作發生的地方；前面是主詞「一狼」，「洞」站在動詞的位置。
  4. 所以「洞」在這裡是名詞當動詞用。

一開始每一步都要寫出來，就算覺得很簡單也要寫。目的是把「憑感覺」變成「有根據」。練熟以後，才可以在腦中直接跑完。

五文言文小幫手

先認識常見虛字

文言文難懂，很大一部分是卡在這幾個虛字。先記住它們最常見的意思：

虛字常見意思例子
之他／牠／它；的；往、到蹄之（踢牠）
其他的、牠的；其中的其一犬坐於前（其中一隻）
而而且、然後；卻學而時習之（學了然後按時溫習）
以用；因為；來（表示目的）意將隧入以攻其後也（來攻擊）
於在；到；比坐於前（坐在前面）
者……的人、……的事物知者（有智慧的人）
也放在句尾，表示肯定、判斷的語氣意將隧入以攻其後也

逐字對譯

把文言句子一個字一個字翻成白話，再讀讀看順不順。翻不順的地方，常常就是有轉品或省略主詞。

驢　不　勝　怒，蹄　之。

驢子／不／能承受／憤怒，（驢子）用蹄踢／牠。

「蹄」如果只翻成「蹄子」，句子就不通。翻不通的地方，就是「蹄」換了詞性。

注釋一定要讀

課本的注釋常常就是考題，讀課文時要一起看。

六怎麼練最有效？

  1. 用判斷卡，每一步都寫出來。
  2. 整理「轉品分類筆記」。準備四頁，分別寫上四種轉品類型。學到新例子，就放進對應的那一頁。一學期累積下來，你會自己看出規律。
  3. 反過來自己造。例如：用名詞當副詞形容很冷 → 冰冷；用形容詞當動詞寫秋天來了 → 秋風黃了銀杏。會自己造，才代表真的懂了。
  4. 每天少量就好。每天 3～5 題，每題都用判斷卡完整分析，效果比一次寫一大張考卷好。

✍️ 練習題

選擇題

A. 選擇題：畫線的字屬於哪一種轉品？

做題前，先在腦中跑一次判斷卡：本來的詞性 → 翻白話 → 看前後 → 下結論。

「雪白的牆壁」

雪白 → 像雪一樣白。「雪」本來是名詞，放在形容詞「白」前面修飾它，所以是名詞當副詞。

〈狼〉「一狼洞其中」

一狼洞其中 → 一隻狼在裡面打洞。「洞」本來是名詞，在句子裡站在動詞的位置，所以是名詞當動詞。

「春風又綠江南岸」

翻成白話：春風又使江南岸變綠。「綠」本來是形容詞，後面接受詞「江南岸」，所以是形容詞當動詞。

「山坡上一片蒼翠」

「一片」是數量詞，後面通常接名詞。「蒼翠」本來是形容詞，這裡指「蒼翠的草木」，所以是形容詞當名詞。

「抱頭鼠竄」

鼠竄 → 像老鼠一樣逃竄。「鼠」修飾動詞「竄」，所以是名詞當副詞。

〈黔之驢〉「驢不勝怒，蹄之」

蹄之 → 用蹄踢牠。「蹄」本來是名詞，後面直接接受詞「之」，所以是名詞當動詞。

「挑肥揀瘦」

挑肥揀瘦 → 挑肥的（東西）、揀瘦的（東西）。「肥」放在動詞「挑」後面當對象，所以是形容詞當名詞。對稱位置的「瘦」也一樣。

「紅了櫻桃，綠了芭蕉」

紅了櫻桃 → 櫻桃變紅了。「紅」後面接了「了」，表示一種變化，所以是形容詞當動詞。

《論語》「學而時習之」

時習之 → 按時溫習它。「時」本來是名詞（時間），放在動詞「習」前面修飾它，所以是名詞當副詞。

「衣錦還鄉」（衣：ㄧˋ）

衣錦 → 穿著錦繡的衣服。「衣」本來是名詞，後面接受詞「錦」，所以是名詞當動詞。讀音也跟著變成ㄧˋ。

「日新月異」

日新 → 每天都有新的變化。「日」修飾後面的「新」，表示時間，所以是名詞當副詞。對稱位置的「月」也一樣。

「嫌貧愛富」

嫌貧 → 嫌棄貧窮的人。「貧」放在動詞「嫌」後面當對象，所以是形容詞當名詞。

〈狼〉「其一犬坐於前」

犬坐 → 像狗一樣坐著。「犬」修飾動詞「坐」，所以是名詞當副詞。這裡的主詞是「其一」（其中一隻狼），不是狗喔！

「一樹火紅」的「火」

火紅 → 像火一樣紅。「火」修飾形容詞「紅」，所以是名詞當副詞。

「一樹火紅」的「火紅」整個詞，在這句話裡是：

「一樹」是數量詞，後面通常接名詞。「火紅」在這裡指「火紅的花、火紅的景象」，所以是形容詞當名詞。和上一題對照：先看清楚題目框的是哪個字！

「山明水秀」：已知「山」是名詞、「明」是形容詞，那「秀」是？

用對稱結構：「山明」對「水秀」，「明」和「秀」在對稱位置，詞性相同，所以「秀」是形容詞。

下列畫線的字，哪一個的轉品類型和其他三個不同？

蜂擁（像蜂群一樣擁來）、蠶食（像蠶一樣吃）、鼠竄（像老鼠一樣逃），都是名詞當副詞。「衣錦」是穿著錦衣，屬於名詞當動詞。

★ 挑戰題「除暴安良」的「安」

除暴安良 → 除掉殘暴的人，使善良的人安定。「安」本來是形容詞，後面接受詞「良」，翻譯多了「使……」，所以是形容詞當動詞。另外，「暴」和「良」都是形容詞當名詞（殘暴的人、善良的人）。

B. 判斷卡練習：每一步都寫出來

「狼吞虎嚥」的「虎」

① 名詞（老虎）

② 像老虎一樣嚥下去（多出「像……一樣」）

③ 後面接動詞「嚥」；和對稱位置的「狼」一樣，都在動詞前面

④ 名詞當副詞

「紅了櫻桃，綠了芭蕉」的「綠」

① 形容詞（顏色）

② 芭蕉變綠了（多出「變」）

③ 後面接「了」和「芭蕉」，表示一種變化；和對稱位置的「紅了櫻桃」結構一樣

④ 形容詞當動詞

〈黔之驢〉「驢不勝怒，蹄之」的「蹄」

① 名詞（驢子的蹄）

② 驢子用蹄踢牠（多出「用……踢」這個動作）

③ 後面直接接受詞「之」（牠，指老虎）

④ 名詞當動詞

「嫌貧愛富」的「富」

① 形容詞（富有）

② 喜愛富有的人（多出「……的人」）

③ 前面是動詞「愛」，「富」是被愛的對象；和對稱位置的「貧」一樣

④ 形容詞當名詞

C. 分類筆記練習

把下面八個畫線的字，分到四種轉品裡：

冰冷　／　蠶食　／　星羅棋布　／　秋風黃了銀杏
一池碧綠　／　以大欺小　／　除暴安良　／　春風又綠江南岸

① 名詞當副詞：冰冷（像冰一樣冷）、蠶食（像蠶一樣吃）、星羅棋布（像星星一樣羅列）

② 名詞當動詞：這一題沒有！（分類時也要敢說「沒有」）

③ 形容詞當動詞：秋風黃了銀杏（使銀杏變黃）、春風又綠江南岸（使江南岸變綠）

④ 形容詞當名詞：一池碧綠（碧綠的水）、以大欺小（弱小的一方）、除暴安良（殘暴的人）

D. 自己造

① 冰冷、雪白、墨黑（像墨一樣黑）

② 秋風黃了銀杏，也紅了楓葉。

③ 傍晚的海面上，一片金黃。／打開窗戶，滿眼翠綠。

只要說得出「為什麼是這種轉品」，自己造的答案也都算對。
